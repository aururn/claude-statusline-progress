# スタイル一覧

`--style=<name>` で選ぶ．指定しない場合は `pips` になる．色は 24-bit color で出すので，Windows Terminal などの true color に対応したターミナルが必要．

## pips

タスク 1 件を 1 つの点で表す．完了は mint の `●`，作業中は amber の `◉`，未着手は暗い `○`．タスクが 15 件以上になると `aurora` に切り替わる．

```
● ● ● ◉ ○ ○ 3/6 テストを修正中 23m
```

## aurora

1/8 マス単位で伸びるバー．進むにつれて coral，amber，mint の順に色が変わる．

```
████████░░░░░░░░  50% 3/6 テストを修正中 23m
```

## pill

背景色で塗った棒の中に，件数と割合を書く．全部終わると mint に変わる．

```
     3/6 · 50%      テストを修正中 23m
```

## line

細い線と割合だけの控えめな表示．

```
━━━━━━━━━━╸━━━━━━━━━ 50% テストを修正中 23m
```

## タスク一覧が無いとき

スタイルに関係なく，今の依頼での作業の量を出す．

```
◌ 23m · 61 tools · 11 files
```

`node statusline-progress.js --demo` を実行すると，全てのスタイルを色付きで表示する．
